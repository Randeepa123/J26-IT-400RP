2. GENERATION METHOD
----------------------------------------------------------------------
  Model: Two-state Markov chain (wet/dry) + Gamma intensity distribution

  A. Calibration (per calendar slot: 3 per month x 12 months = 36 slots)
     p_wet   : proxy wet-day fraction = period_total / (n_days x 35 mm)
               35 mm/day is a soft upper bound for Ratnapura. CANNOT be
               directly validated -- no daily observations available.

     Markov  : P(wet|wet)=p11, P(wet|dry)=p01 from p_wet + persistence=0.65
               Persistence is a climatological prior for tropical humid zones.
               CANNOT be calibrated from aggregated source data.

     Gamma   : shape/scale by method-of-moments on period daily-average totals.
               Fitted to inter-period variability, NOT true daily variability.

  B. Disaggregation (per source period within target window)
     1. Run Markov chain for n_days of the period.
     2. Draw Gamma amounts for wet days.
     3. Rescale amounts so they sum EXACTLY to the observed period total.
     4. Boundary periods apportioned proportionally by day fraction.

  C. Random seed: 42 (fully reproducible)

7. LIMITATIONS AND SCIENTIFIC CAVEATS
----------------------------------------------------------------------
  The following cannot be validated from the available source (aggregates only):

  a) Daily wet-day frequency -- estimated via heuristic, not observation.
  b) Markov persistence -- set as a climatological prior (0.65).
  c) Extreme daily rainfall -- Gamma fitted to period means, not daily extremes;
     true daily maxima at Ratnapura can exceed 200 mm; these may be under-
     represented in this simulation.
  d) Within-period temporal structure -- rescaling removes true day-to-day
     autocorrelation; inter-day dependence is from the Markov chain only.
  e) Monsoon onset/retreat timing -- not explicitly modeled.

  RECOMMENDATION: Use as preliminary stochastic forcing for hydropower
  simulations. Do NOT substitute for observed daily records in formal
  hydrological calibration, flood frequency analysis, or operations.
